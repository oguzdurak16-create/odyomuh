# ODYOMUH v2.3.0

## Ana sayfa kartları

- Türkçe yazı kartları premium düzene geçirildi.
- Kartlara kategori, tahmini okuma süresi, tarih, arşiv bilgisi ve belirgin okuma bağlantısı eklendi.
- Editör seçkisi kartları tarih ve alt eylem alanıyla yenilendi.
- İngilizce yazı kartları aynı görsel sisteme uyarlandı.
- Mobil kart ölçüleri ve etiket taşmaları düzenlendi.

## Footer

- Footer dört bölümlü yayın yapısına dönüştürüldü.
- Logo, açıklama, arşiv araması ve sosyal medya bağlantıları eklendi.
- Keşfet, öne çıkan konular ve kurumsal bağlantılar ayrıldı.
- Dil, gizlilik ve sitemap bağlantıları alt satıra eklendi.
- Açık ve koyu tema uyumu tamamlandı.

## Etiket indeksi

- `/etiketler` rotası eklendi.
- Tüm etiketler alfabetik gruplara ayrıldı.
- Etiket araması eklendi.
- Her etikette yazı sayısı gösteriliyor.
- Popüler etiketler hero alanında listeleniyor.
- Masaüstü ve mobil tasarım tamamlandı.
- Menü, mobil menü, footer ve sitemap içine Etiket İndeksi bağlantısı eklendi.

## Doğrulama

- `npm run content:check`: başarılı.
- `npm run build`: başarılı.
- Ana sayfa: HTTP 200.
- `/etiketler`: HTTP 200.
- Toplam 246 statik/dinamik rota üretildi.
